Downloads

The full dataset behind this browser, in two formats. Both are regenerated directly from the same source table, so they always match what you see on the Browse page.

CSV

One row per variant, flat columns, ready for Excel, R, or pandas. Best for spreadsheet review or quick filtering outside the browser.

JSON

The same records as an array of objects, one shared schema across all genes and antigen groupings. Best for scripts, notebooks, or feeding into another tool.

Schema

Data release: 2026-08-13

Every record in both files shares this field set. Fields not applicable to a given variant (e.g. base-editing feasibility on a large deletion) are populated with N/A or left empty rather than omitted, so both files always have consistent columns.

system, system_label, gene, chromosome, strand, isbt_system_code, hgvs, phenotype, allele_background, region, variant_id, alternative_notation, variant_category, mutation_type, grch38_coordinate, dbsnp_rs, reference_allele, alternate_allele, isbt_allele_designation, molecular_mechanism, validation_level, validation_cell_line, population, gnomad_v4_af_global, gnomad_v4_af_afr, gnomad_v4_af_eur, topmed_af, be4max_feasibility, abe8e_feasibility, be_guide_sequence_notes, bystander_edits, first_report_year, key_reference, pubmed_source_url, audit_status, gnomad_url

Every column is defined on the Methods page: general fields under Field definitions, and validation tiers, audit statuses, and base-editing feasibility ratings under their own named sections.

Before you use this data

Cite both the database and the original literature. Downloading the flat file does not change the citation requirement, every variant's key_reference and pubmed_source_url columns point to the study the finding actually came from; cite that study alongside this database. See the Citation page for the exact format.

About this resource

A research catalog of non-coding and regulatory blood group variants, compiled for the study of variant-guided base editing strategies for antigen modulation. Not a clinical or diagnostic tool.
